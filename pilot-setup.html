Use this page to download and run the approved reviewer build package. This distribution path is intended for authorized external evaluators.

Download Reviewer Build ZIP (~108MB)

Extract the ZIP first, then run EngineeringIntelligence.exe from the extracted folder so the required _internal runtime files are available.

It's a large file (~108MB) — the download starts in this tab, so watch your browser's download bar/tray rather than waiting for a new tab to appear.

Launch from shared package

  1. Before extracting, right-click the downloaded ZIP → Properties → check Unblock → OK. Windows marks browser downloads as "from the internet," and if you skip this the app can crash on launch (see Troubleshooting below).
  2. Extract the reviewer ZIP file.
  3. Open the extracted folder and run EngineeringIntelligence.exe.
  4. If Windows SmartScreen appears, click More info then Run anyway only if you trust the source.

Do not run a copied standalone .exe outside the extracted package folder.

Troubleshooting

If you see a python313.dll or _internal error, the executable is being run without its bundled runtime folder. Re-extract the ZIP and run from inside that extracted folder.

If your browser shows a temporary extension such as .download while transferring, wait until the download completes and confirms a final .zip filename.

"Unhandled exception... Failed to resolve Python.Runtime.Loader.Initialize" or any error mentioning pythonnet / Python.Runtime.dll: this means the ZIP was extracted before being unblocked, so Windows is still treating files deep inside _internal\ as downloaded from the internet and refusing to load them. Unblocking just EngineeringIntelligence.exe does not fix this — delete the extracted folder, right-click the original .zip → Properties → Unblock → OK, then extract again.

Windows check: right-click EngineeringIntelligence.exe, select Properties, and if blocked, click Unblock before launching.
