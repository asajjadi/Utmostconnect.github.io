Protected Build

Engineering Intelligence Reviewer Build Access

Use this page to download and run the approved reviewer build package. This distribution path is intended for authorized external evaluators.

Download Reviewer Build ZIP (~152MB)

Extract the ZIP first, then run EngineeringIntelligence.exe from the extracted folder so the required _internal runtime files are available.

It's a large file (~152MB) — the download starts in this tab, so watch your browser's download bar/tray rather than waiting for a new tab to appear.

Launch from shared package

  1. Extract the reviewer ZIP file.
  2. Open the extracted folder and run EngineeringIntelligence.exe.
  3. If Windows SmartScreen appears, click More info then Run anyway only if you trust the source.

Do not run a copied standalone .exe outside the extracted package folder.

Troubleshooting

If you see a python313.dll or _internal error, the executable is being run without its bundled runtime folder. Re-extract the ZIP and run from inside that extracted folder.

If your browser shows a temporary extension such as .download while transferring, wait until the download completes and confirms a final .zip filename.

Builds from 2026-08-06 onward fix the "Unhandled exception... Failed to resolve Python.Runtime.Loader.Initialize" crash automatically — the app now strips Windows' "downloaded from the internet" flag from its own files on launch, so no manual unblock step is needed. If you're still seeing this error, you're likely running an older extracted copy; delete it and re-download from the link above.

Builds from 2026-08-21 onward also fix a "cannot open"/extraction error some reviewers hit — the package no longer bundles an unused reference-data folder whose deeply nested file names could exceed Windows' 260-character path limit. If extraction fails, re-download the current build from the link above.
