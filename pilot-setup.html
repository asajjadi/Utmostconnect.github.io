Engineering Intelligence Pilot Setup

Use one of the options below to run the pilot locally. This page is the recommended run path for external users.

Download Windows Launcher (.lnk) Open Source Repository

Option A: Launch from shared package

  1. Download and extract the shared pilot ZIP package.
  2. Inside the extracted folder, run EngineeringIntelligence.exe (or your packaged launcher).
  3. If Windows SmartScreen appears, click More info then Run anyway only if you trust the source.

If your team received only the launcher shortcut, make sure the target application folder from the ZIP package is in place first.

Option B: Run from source

  1. Clone the repository branch rc2-public-case-validation.
  2. Install dependencies with pip install -r requirements.txt.
  3. Run with python -m streamlit run mvp/app.py.
  4. Open http://localhost:8501 in your browser.

Troubleshooting

If the launcher does not open, your shortcut target is likely missing on that machine. Use Option B (source run) or request a fresh packaged ZIP with the executable included.
