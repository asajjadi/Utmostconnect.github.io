Troubleshooting

Live demo: if the page shows a red error box instead of the app, refresh once (it may still be waking up); if it persists, let Amir know — the demo may be mid-update.

Local build: a python313.dll or _internal error means the executable is being run without its bundled runtime folder — re-extract the ZIP and run from inside that extracted folder. If your browser shows a temporary .download extension while transferring, wait for it to finish and confirm a final .zip filename. Builds from 2026-08-06 onward auto-fix the "Failed to resolve Python.Runtime.Loader.Initialize" crash; builds from 2026-08-21 onward also fix a Windows path-length extraction error. If either shows up, delete any old extracted copy and re-download from the link above.
